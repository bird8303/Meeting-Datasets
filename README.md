# Meeting-Datasets
The noise in the AIMeeting dataset includes common sounds encountered during meetings, such as coughing, keyboard typing, table knocking, air-conditioner noise, and fan noise.

The meeting dataset presented in this repository is created by mixing clean speech from the VoiceBank dataset with meeting noise extracted from the AIMeeting dataset. The clean training set is taken from the VoiceBank dataset, while the noisy training set is the result of mixing. The clean test set is taken from the VoiceBank dataset, and the noisy test set is also the result of mixing. The noisy training set is generated by mixing the meeting noise with clean speech at SNRs of 0, 5, 10, and 15 dB, whereas the test set is mixed at 2.5, 7.5, 12.5, and 17.5 dB.
